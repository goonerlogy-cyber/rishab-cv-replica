01SEARCH ENGINE

Sift

Search, explained.

A from-scratch, typo-tolerant, search-as-you-type engine running in a Web Worker over 10k records, with faceting, highlighting, a live latency readout and a per-hit ranking explainer.

  • Compressed radix trie — prefix search + bounded typo matching
  • Positional inverted index + bitset facets
  • Six ranking criteria → top-K heap with full tie-break explanation

Source to WebAssembly.

A small language that compiles to WebAssembly in your browser, with a live editor and inspectable compiler stages.

  • Pipeline: source → lexer → parser → type checker → binary emitter → WASM → worker runtime
  • Mandelbrot demo writes 65,536 pixels through a canvas host
