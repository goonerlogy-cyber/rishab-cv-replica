# JAFN Portfolio Layout

A static portfolio layout inspired by [rishab.cv](https://rishab.cv), with project content for [justalivefornothing](https://github.com/justalivefornothing).

## Featured projects

- [Sift](https://github.com/justalivefornothing/sift-search) — Local search over generated records, with ranking explanations.
- [Kiln](https://github.com/justalivefornothing/kiln-lang) — A small language that compiles to WebAssembly in the browser.
- [Eddy](https://github.com/justalivefornothing/eddy-fluid) — An interactive WebGL2 fluid simulation.

The page also links to other experiments and a philosophy manuscript.

## Preview

Open `index.html` in a browser, or serve the repository root with a static web server. The page uses `styles.css` and `script.js` and requires no build step.

## Deploy

Publish the repository root with a static host. Verify the deployed page matches the intended `index.html` before sharing its URL.
